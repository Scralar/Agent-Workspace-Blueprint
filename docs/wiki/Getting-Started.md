# Getting started

Point an agent at the live kit. Do not copy this repository.

## 1. Paste this into the agent

Use it in the project you want to set up, not in a clone of this repo unless you are changing the kit itself.

```text
Follow https://github.com/Scralar/Agent-Workspace-Blueprint/tree/main/blueprint
for *this* project. Start at blueprint/README.md.
Do not copy that repository's .cursor/ tree or anyone else's MCP list.
```

The agent reads [`blueprint/README.md`](https://github.com/Scralar/Agent-Workspace-Blueprint/blob/main/blueprint/README.md), picks a path, and scaffolds **in your repo**.

## 2. Pick a path

| Your situation | Path |
|----------------|------|
| Tiny repo (script pack, plugin, exercises) | [`blueprint/minimal.md`](https://github.com/Scralar/Agent-Workspace-Blueprint/blob/main/blueprint/minimal.md): one `AGENTS.md`, done |
| Existing repo with history | [`blueprint/adopt.md`](https://github.com/Scralar/Agent-Workspace-Blueprint/blob/main/blueprint/adopt.md) plus the matching shape |
| New public repo | [`blueprint/public/`](https://github.com/Scralar/Agent-Workspace-Blueprint/tree/main/blueprint/public) |
| New private repo, one maintainer | [`blueprint/private-solo/`](https://github.com/Scralar/Agent-Workspace-Blueprint/tree/main/blueprint/private-solo) |
| New private repo, collaborators or parallel agents | [`blueprint/private-team/`](https://github.com/Scralar/Agent-Workspace-Blueprint/tree/main/blueprint/private-team) |

More detail: [The kit](https://github.com/Scralar/Agent-Workspace-Blueprint/wiki/The-Kit).

## 3. Copy is optional

A local snapshot of `blueprint/` (for example `.cursor/brief/`) is fine when you are offline or want a pinned revision. Note the source URL. Do not copy this repository's `.cursor/` tree or anyone else's MCP list.

## 4. Later sessions

The consumer repo should now have its own map (`AGENTS.md` or that project's equivalent). Point later agents at *that* file, not at this wiki.

## Changing the kit itself

If you are working **on** [this GitHub repository](https://github.com/Scralar/Agent-Workspace-Blueprint), start at [This repository](https://github.com/Scralar/Agent-Workspace-Blueprint/wiki/This-Repository) and [Contributing](https://github.com/Scralar/Agent-Workspace-Blueprint/wiki/Contributing).
