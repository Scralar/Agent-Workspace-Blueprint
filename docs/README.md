# Docs

Why the kit looks like this, and the source pages for the [GitHub wiki](https://github.com/Scralar/Agent-Workspace-Blueprint/wiki). Not the kit ([`blueprint/`](../blueprint/README.md)). Not the human or agent doors (root [`README.md`](../README.md), [`AGENTS.md`](../AGENTS.md)).

| Path | Open when |
|------|-----------|
| [wiki/](wiki/Home.md) | Wiki source (Home, sidebar, getting started). Published by `node scripts/publish-wiki.mjs` |
| [adr/](adr/README.md) | A kit decision needs why, or you are writing an ADR |

Process files (`CONTRIBUTING.md`, `COLLABORATORS.md`, `LICENSE`, and the rest) live at the **repo root**. Do not restate them here.

New ADR: copy [adr/TEMPLATE.md](adr/TEMPLATE.md), take the next number, add a row to [adr/README.md](adr/README.md) and [wiki/Decisions.md](wiki/Decisions.md), then publish the wiki.
